# Football Data Visualizations

A collection of data visualizations I built while learning sports data analytics, with a focus on football (soccer). Each visualization type was applied to a real dataset or case study to practice both the analytics and the charting techniques.

## Contents

### Scatter Plots & Crosshairs
Used to plot Goals For vs. Goals Against for the **FKF Premier League 2024/25** season, highlighting team attacking and defensive performance at a glance.

### Bar Charts & Lollipop Charts
Simple bar charts and lollipop charts used to visualize the **FKF Premier League 2024/25** league table.

### Treemaps
Used for opponent threat analysis.
**Case study:** Arsenal 2025/26 threat analysis.

### Radar Charts
Used for player comparisons across key performance metrics.

### Cumulative Line Charts
Used to track running totals across a season -- **EPL 2025/26**.
**Case study:** Manchester United vs. Manchester City running points/goals totals.

### Match Analysis Visuals
Pass heat maps, pass maps, passing networks, and shot maps used for individual match analysis.

## Purpose
This repo is primarily a learning log--a way to practice translating raw football data into clear, insightful visuals. Expect ongoing additions as I explore new chart types and case studies.
